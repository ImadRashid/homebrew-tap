# homebrew-tap

Homebrew tap for [Imad Rashid's](https://github.com/ImadRashid) tools.

## Available formulae

- **[reclaim](https://github.com/ImadRashid/reclaim)** — a developer-aware Mac cleaner CLI

## Install

```sh
brew install ImadRashid/tap/reclaim
```

Or tap once and install by short name:

```sh
brew tap ImadRashid/tap
brew install reclaim
```
